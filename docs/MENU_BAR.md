# 菜单栏快捷压缩

默认在系统菜单栏显示 LiteZip 的单色压缩包图标。将 Finder 中的本地文件或文件夹拖到图标上，图标会高亮；松开后立即加入现有任务队列，保存到首个项目所在目录，同名结果自动编号。可以在面板中勾选“每次选择保存位置”，改为先确认输出位置再压缩。源文件不会移动或删除。多个项目会打包到一个压缩包，拖入已有压缩包也会按普通文件压缩，不会自动进入解压模式。

点击图标可选择格式、选择文件，并查看最近三项任务、进度与错误。正在处理的任务可以取消，成功结果可在 Finder 显示。默认格式来自应用设置，此面板中的格式选择作用于快捷压缩；压缩等级使用设置中的默认等级。不使用主窗口里尚未提交的密码或分卷设置；需要加密、分卷或分别压缩时使用主窗口。

启用菜单栏入口时，关闭主窗口继续运行；通过面板的“打开主窗口”恢复窗口，通过“退出”结束应用。退出时仍沿用原有的运行中任务确认与取消清理流程。设置的“外观”部分提供“在菜单栏显示 LiteZip”开关。

实现使用 `NSStatusItem`、支持 `.fileURL` 的 `NSView` 拖放目标、`NSPopover` 和独立的保存对话框。快捷入口不会替换主窗口的文件选择，复用 `AppModel.enqueue` 和现有压缩引擎。仅接收已经存在的本地文件，最多 1000 项；网页链接、空输入、已经消失的文件及不允许复制的拖放会被拒绝。GZIP/BZIP2/XZ/ZSTD 的单文件约束及 RAR 引擎要求保留。

验证：`bash Scripts/test-menu-bar.sh` 测试实际拖放目标的接收与回调，覆盖中文与特殊字符文件夹、已有压缩文件、多项去重、仅复制操作、无效输入与数量上限，并确认源文件未变。`Scripts/build.sh` 构建 arm64/x86_64 通用 App。Finder 向系统菜单栏的完整拖拽及弹出面板仍需真实桌面交互验证；当前电脑控制工具主要读取主窗口，未能完整捕获菜单栏弹出面板。
