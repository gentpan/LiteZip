# 0.3.0 验证记录

## 自动测试

`LITEZIP_RAR_TEST_ENGINE='/absolute/path/to/rar' LITEZIP_LARGE_TESTS=1 swift test`：29 组测试全部通过，包括参数化格式与安全案例。本机使用 RARLAB 官方 macOS ARM 7.23 完整软件包进行编码测试；该引擎不进入仓库或发布产物。

未指定 RAR 测试引擎时跳过五组编码集成测试，其余测试照常运行。CI 不下载专有编码器。

- ZIP、7Z、TAR、TAR.GZ、GZIP、BZIP2、XZ、ZSTD 往返与引擎完整性校验。
- 多级目录、中文与 Emoji 文件名、隐藏文件、零字节文件、空 ZIP、标准 TAR 的 `./` 路径。
- ZIP ASCII 密码与 7Z 中文／Emoji／长密码；错误密码不发布结果，Unicode ZIP 密码给出明确错误。
- `@`、`*`、`-` 开头等特殊文件名的字面量处理。
- 越界路径、绝对路径、反斜杠、大小写重名、换行名称、符号链接、硬链接、FIFO 拒绝。
- 展开限制、损坏／截断、取消与临时文件清理、重复输出自动编号，包括 TAR.GZ 复合扩展名。
- libarchive 上游 RAR4 和 RAR5 压缩样本的真实解压与校验。
- 引擎在退出前发送的小进度块会即时交付，而不是等待输出缓冲区填满。
- ZIP／7Z 加密分卷，随机数据跨三卷往返、各卷尺寸限制、从后续卷归一到首卷、重名输出、错误密码、缺中间卷和符号链接分卷拒绝。
- 普通归档和分卷模式取消后均不发布结果，并清理临时目录。
- ZIP／7Z 存储等级、分卷大小解析／非法单位／范围拒绝、不支持分卷的格式拒绝。
- 四种多文件格式的 Mac 资源排除开／关；普通隐藏文件与带星号的字面文件名保留。
- 分别压缩规划生成独立归档，带点的文件夹名称保留。
- 压缩 TAR 内容预览返回内层文件；预览和校验均拒绝内层符号链接、硬链接与 FIFO。
- 1 GiB 零字节填充的稀疏源文件，流式压缩与解压并校验展开文件尺寸。数据高度可压缩，不代表随机数据吞吐性能。
- RAR 六档压缩等级、中文／Emoji 密码、文件名加密、错误与缺失密码、重复输出编号、过长密码拒绝。
- RAR 字面 `*` 文件名不会包含匹配的未选文件，`@`、`-`、中文目录、隐藏文件、空目录与资源排除开／关往返；源数据不修改。
- RAR 随机数据加密三卷及十一卷往返，验证 .part1 与 .part01 编号，从 .part11 正确归一到 .part01，各卷尺寸限制、缺中间卷、符号链接分卷拒绝。
- RAR 源链接与顶层同名输入拒绝、取消不发布结果并清理快照；无引擎给出专门错误；无效引擎拒绝，常用符号链接安装路径可解析。

应用和核心使用 Swift 6 编译；Release 配置无应用源码编译警告。Xcode 对无 AppIntents 依赖的目标产生元数据跳过提示，未使用此框架。

## 构建与签名

- App、Finder 扩展、7zz、zstd 均为 arm64 + x86_64 universal Mach-O。
- Apple Silicon 原生实测；7zz 的 x86_64 slice 已通过 Rosetta 启动检查；Intel 真机未验收。
- Developer ID 签名含 Hardened Runtime 与时间戳；`codesign --verify --deep --strict` 通过。
- 证书只从本机 Keychain 调用，仓库不包含证书、私钥或公证凭据。
- **未公证**：`spctl` 返回 `Unnotarized Developer ID`。尚未满足正式发布 Gatekeeper 门禁。
- Finder 扩展的 `NSExtensionPointIdentifier` 和应用版本由构建脚本校验，扩展可由 `pluginkit` 注册。
